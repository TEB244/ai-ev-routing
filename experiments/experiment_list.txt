Each experiment is a directory within this directory.

Each experiment directory should contain:
- `config.yaml`: Configuration for the experiment.
- `description.txt`: A description of the experiment.
- `Experiment Analysis.ipynb`: A notebook for analyzing the results of the experiment.

Experiments in the range 40-3999 are not used in the paper, but helped test certain edge behaviors and informed the development process.

Experiments 4000 and onwards are combinations of the following parameters.

There is one experiment for each combination of the following parameters:
- Aggregation level: [50, 5, 1] (3 levels)
- Model: [DQN, REINFORCE, CMA, DQN + ODT, REINFORCE + ODT] (5 models)
- Seed: [1234, 5555, 2020, 2468, 11110, 4040, 3702, 16665, 6002] (9 seeds)
- Season: [spring, summer, autumn, winter] (4 seasons)

Number of combinations = 3 * 5 * 9 * 4 = 540 experiments

These are spread over 3 batches, 4000-4179, 5000-5179, and 6000-6179.
Each batch covers 3 of the 9 total seeds.

Each experiment can be run to train the model, or to load a pretrained model and evaluate it.
The selection of training or evaluation is done by running the main.py file and including -eval True or -eval False (default is False).

Experiments 4000-6179 are ordered to cycle through each model (starting with DQN), and then each aggregation level (starting with 50) and then each seed (starting with 1234), and then each season (starting with spring).

Experiment 4000:
- Model: DQN
- Seed: 1234
- Season: spring
- Aggregations: 50

...

Experiment 4179:
- Model: REINFORCE + ODT
- Seed: 2020
- Season: winter

This repeats for the 5k and 6k batches but with different starting seeds.


Set Name: Reward-weight sensitivity analysis [7000-7179]
-------------------------------------------------------------------------
Reward parameterisation:
   R = -(w_d * D * f_d + w_T * max_tau * f_t + w_e * E * f_e)

   f_d, f_t, f_e are unit-conversion scales held FIXED at baseline:
     distance_scale = 100     (degrees lat/long -> ~ km)
     traffic_scale  = 1       (cars at peak station)
     energy_scale   = 0.001   (Wh -> kWh)
   These convert the simulator's raw quantities to natural physical units.

   w_d, w_T, w_e are tunable per-term WEIGHTS, default 1.0. These are
   what we sweep here.

Sweep values (same set for each weight):
   weight in {0, 1, 5, 7, 10}
     0  = ablation (term removed from reward entirely)
     1  = baseline (matches all prior 4xxx/5xxx/6xxx experiments)
     5, 7, 10 = increasing emphasis on this term

Per (model, swept weight, value) we run 3 seeds (1234, 5555, 2020) in
spring at aggregation level 50. Episode counts inherit from the existing
4xxx baseline configs per model (200 for DQN/REINFORCE/CMA, 80 for ODT).

Total combinations = 4 models * 3 swept weights * 5 values * 3 seeds
                   = 180 experiments.

Block layout:
- 7000-7044: DQN
    - 7000-7014: distance_weight sweep
    - 7015-7029: traffic_weight sweep
    - 7030-7044: energy_weight sweep
- 7045-7089: REINFORCE
    - 7045-7059: distance_weight sweep
    - 7060-7074: traffic_weight sweep
    - 7075-7089: energy_weight sweep
- 7090-7134: CMA
    - 7090-7104: distance_weight sweep
    - 7105-7119: traffic_weight sweep
    - 7120-7134: energy_weight sweep
- 7135-7179: ODT
    - 7135-7149: distance_weight sweep
    - 7150-7164: traffic_weight sweep
    - 7165-7179: energy_weight sweep

Within each 15-experiment sweep block, ordering is value-major then
seed-minor:
  offset +0,1,2   weight=0  (ablation)            seeds 1234, 5555, 2020
  offset +3,4,5   weight=1  (baseline)            seeds 1234, 5555, 2020
  offset +6,7,8   weight=5                        seeds 1234, 5555, 2020
  offset +9,10,11 weight=7                        seeds 1234, 5555, 2020
  offset +12,13,14 weight=10                      seeds 1234, 5555, 2020

The baseline (weight=1) configs at offset +3/+4/+5 are functionally
identical across the three sweeps for any given (model, seed) - they
all reduce to the canonical reward used by all prior 4xxx experiments.
Three of them per (model, seed) exist so that each of the three sweeps
is a self-contained 5-point series. You can either run all 180 or run
only the 12 unique baseline configs (one per model x seed) and reuse
those results across the three sweeps.

Configs are generated by `generate_sensitivity_experiments.py` at the
repo root. The reward computation reads `*_weight` and `*_scale` fields
from `environment_settings`; both default to baseline values
(weights=1.0, scales=100/1/0.001) when absent, so prior configs continue
to behave exactly as before.
